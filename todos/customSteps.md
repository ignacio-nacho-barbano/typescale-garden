# Feature name

Custom typescale steps

## Description

Currently, there are 6 fixed steps mapping directly to h1 to h6, the user should be able to add extra custom steps on each end
ALSO they should be able to add silent steps (Steps that are impacting the scale, but not used)
This should all be customizable through a new steps modal that opens on a "customize steps" button close to the size inputs after it
This modal should also show the inputs for mobile and desktop and a live view of each step's size on an "Ab" text to compare each

I should be able to add empty steps as blocks for example in between my h4 and h3
Modal should look like

| CUSTOM STEPS                                    | X //close button |
| ----------------------------------------------- | ---------------- |
| inputs for all size related fields visible here |
| -                                               |

| Ab      | Ab    | Ab    | Ab                                      | Ab                                                                                      | Ab       | Ab       | Ab       | Ab       | Ab       |
